Know before you play

Ferry reads the game first.

Before anything runs, Ferry checks whether a game is 32- or 64-bit, which graphics it uses, what it needs and what might block it, then picks the engine that suits it.

  • Drop in .exe, .msi or .bat files, folders, or .zip, .rar and .7z archives
  • Finds the real game among several programs
  • Visual C++, DirectX, .NET, XNA, PhysX and codecs installed once, for every game

Fix a game with a switch

Every setting explained.

Engine, MetalFX upscaling, Retina, frame rate limit, VSync, Use DirectX 9 and more, each with an ⓘ that says what it does. Options that wait on another setting say what they need.

  • Per-game settings, kept apart from every other game
  • Save backups, launch arguments, ⌘ as Ctrl

Something wrong?

Pick what you see.

Black screen, stutter, crackling sound, a crash: Troubleshoot walks you through the fixes for that problem, one at a time, and reads the game's log for errors it recognises.

  • Fixes tuned to each game's engine
  • Report a Bug… with the details filled in

Mods and fixes

Found for you.

Ferry searches PCGamingWiki and GitHub for a game's fixes and mods, installs them, and removes them again cleanly with the original files put back.

How it works

Four engines. Ferry picks one.

Ferry reads each program without running it. If a game closes right after starting, it shows why and offers the next engine to try. You can always pick one yourself.

GameEngine
64-bit DirectX 11 / 12D3DMetal
Apple's own translator, straight to Metal
DirectX 9, 10, 32-bit DirectX 11, VulkanMach9
Straight to Metal, no Rosetta
OpenGL and Clickteam gamesMullion
DirectX and OpenGL 4.6 to Metal, no Rosetta
Installers and older 32-bit gamesWine Staging
WineD3D or DXVK

What can't run: games with kernel anti-cheat (Valorant, Fortnite and most competitive shooters), Windows drivers, 16-bit programs and Microsoft Store packages. The Compatibility Check tells you before you add a game.

Questions

Good to know.

How do I play Windows games on a Mac?

Download Ferry, drag the game's .exe, folder or archive onto its window (or install Steam from Ferry), and press Play. Ferry picks the engine and installs what the game needs.

Is Ferry a free alternative to CrossOver or Whisky?

Yes. Like them it runs Windows games through Wine and Apple's D3DMetal, but it's free, picks the engine and settings per game for you, and keeps its engines up to date with one click.

Does it work with Steam games?

Yes. Ferry installs Steam for Windows in one click and lets you add its games to your library. Games with kernel anti-cheat can't run on any Mac translation layer.

Is it really free?

Yes. Ferry costs nothing, and so do all the engines and libraries it downloads.

Do I need to know about Wine?

No. That's the point of Ferry. If you do, every engine and setting is there for you to change.

Where are my games and saves?

Games run from wherever you keep them. Each game's saves are kept apart from its environments, so switching engines never loses them.

Install

Four steps, once.

  1. Download Ferry (the .dmg file) and open it.
  2. Drag Ferry into Applications.
  3. macOS blocks it the first time: in System Settings ▸ Privacy & Security, click Open Anyway.
  4. Click Install on Ferry's setup screen and let it finish.

Needs a Mac with Apple silicon (M1 or later) and macOS 14 or later. Mach9 needs macOS 26.4; D3DMetal 4 needs macOS 27.
